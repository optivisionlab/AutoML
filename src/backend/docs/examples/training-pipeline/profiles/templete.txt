phần 1: fe kết nối với db thì cần fe dùng api /connect-database gửi json 
{
	"db_type": "postgres",  (Bắt buộc: ví dụ "postgres", "mysql", "sqlite",...)
  "database": "tên_database",  // Bắt buộc: Tên database (hoặc đường dẫn file .db nếu là sqlite/duckdb)
  "host": "localhost",         // Tùy chọn, mặc định "localhost"
  "port": 5432,                // Tùy chọn (nếu không truyền BE tự gán theo db_type: 5432, 3306, 1433...)
  "user": "tên_user",          // Tùy chọn
  "password": "mật_khẩu",      // Tùy chọn
  "schema_name": "public",     // Tùy chọn (ví dụ "public" với Postgres)
  "extra_params": {} 
}


thành công thì gửi be gửi lại json 
ví dụ 
{
  "success": true,
  "message": "Kết nối cơ sở dữ liệu thành công!",
  "tables": [
    "customers",
    "orders",
    "products",
    "transactions"
  ]
}

lỗi thì 

{
  "detail": "Kết nối thất bại: <lý do lỗi cụ thể>"
}
